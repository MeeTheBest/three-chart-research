# 子平八字命理分析

将机械排盘与解释性分析分开执行。先使用随附程序计算命盘，再按参考方法交叉验证并形成清晰、克制的解读。

## 工作流

1. 收集并复述输入信息：
   - 公历出生年、月、日。
   - 出生时间，使用 24 小时制并尽量精确到分钟。
   - 性别。
   - 出生地、时区；可获得时补充经纬度。
2. 发现农历日期、时辰称谓、夏令时、时区或出生时间不确定时，先澄清或明确列出采用的假设。不要把农历日期直接传给程序。
3. 运行 `scripts/run_bazi.py` 计算四柱。不要凭语言模型记忆手算干支或节气边界。
4. 阅读 [references/methodology.md](references/methodology.md)，按四柱、日主旺衰、格局取用、十神组合、刑冲合害、大运流年、神煞和盲派技法依次分析。
5. 用至少两类独立信息交叉验证重要结论。结论冲突时如实呈现，不强行调和。
6. 区分“程序计算结果”“传统命理解释”“不确定推测”。推测必须显式标注。
7. 按“命盘摘要、命局总论、四柱详解、组合与互动、大运流年、主题分析、现实建议、局限说明”输出。

## 运行排盘

优先使用当前 Codex 工作区依赖中的 Python。先检查 `sxtwl`：

```bash
python3 -c "import sxtwl"
```

若缺失，将依赖安装到本 Skill 内，避免修改用户的全局 Python：

```bash
python3 -m pip install --target scripts/vendor -r scripts/requirements.txt
```

运行示例：

```bash
python3 scripts/run_bazi.py \
  --date 1990-05-15 \
  --time 14:00 \
  --gender 男 \
  --timezone 8 \
  --latitude 39.9 \
  --longitude 116.4 \
  --location 北京
```

需要结构化数据时追加 `--format json`。需要按特定年份判断当前大运与流年时追加 `--reference-date YYYY-MM-DD`。

## 解读纪律

- 只把用户提供的经历当作待验证信息，不反向迎合或用它替代命盘依据。
- 优先分析刑冲合害和十神组合，再讨论单个神煞；避免靠单一符号下结论。
- 不宣称能确定预测死亡、疾病、灾祸、婚姻成败、财富数额或具体事件日期。
- 不依据八字替用户做医疗、法律、投资、就业、婚育等高影响决定。
- 将内容定位为传统文化与娱乐性反思工具，并提供可由现实证据检验的建议。
- 出生日期、精确时间和地点属于敏感个人信息；只在完成当前任务所需范围内使用，不主动扩散或长期保存。
