## 一、概述

八字（BaZi / Four Pillars）是基于出生年、月、日、时的中国命理分析系统。每柱由一个天干和一个地支组成，共八个字。本文档将 Python 算法排盘与盲派技法相结合，形成一套结构化的命理解读方法论。

核心工具链：Python 脚本处理机械计算（排盘），解读者使用下方技法进行命理分析和综合论断。

## 二、核心原则

原则一：四柱定框架

年柱定祖上/童年基调，月柱定父母/青年运势，日柱定自身/婚姻/中年，时柱定子女/晚年。每柱不是孤立看的。

原则二：日主为中心

所有十神都以日主天干为基准来定。日主的旺衰强弱决定格局走向。

原则三：刑冲合害优先于单星

地支之间的互动（穿 > 冲 > 合 > 破 > 刑）比单个神煞更重要，尤其是盲派的"穿"。

原则四：用神是钥匙

找到用神（喜神）和忌神之后，整个命盘的吉凶判断才有方向。

原则五：大运是时间轴

原局是静态的，大运流年是动态触发。看命一定要结合当前大运。

## 四、技法详解

### 技法一：四柱顺序读法

拿到排盘后，按以下顺序逐一分析每柱：

#### 年柱（祖上宫 / 童年）

- 年干透出什么十神？正官/七杀透年干，祖上有官宦背景
- 年支与日支相冲 → 青少年离家/搬迁
- 年柱纳音看家族气质
#### 月柱（父母宫 / 青年）

- 月令是日主旺衰的关键——月支决定日主得令与否
- 月干透出十神往往是一个人最表面的性格
- 月支藏干看内在潜能
- 月支被冲 → 青年期有重大变动
#### 日柱（自身宫 / 夫妻宫）

- 日支是配偶宫：比肩坐日支 → 婚姻有竞争或晚婚；正财/正官坐日支 → 夫妻关系正派
- 日支被穿或冲 → 婚姻不顺的强烈信号
- 日主强弱看月令+地支根气+天干生扶
#### 时柱（子女宫 / 晚年）

- 时干透食神/伤官 → 子女有出息
- 时支是归息之地，看晚年运势
- 时柱空亡 → 晚年容易空虚或子女不在身边
### 技法二：日主旺衰判断法

日主旺衰是格局的基础。脚本已计算，但你需要理解判断逻辑：

| 因素 | 旺 | 衰 |
| --- | --- | --- |
| 月令 | 得令（日主五行=月令五行） | 失令 |
| 地支根 | 地支有比劫根气 | 无根或根弱 |
| 天干生扶 | 有印星生、比劫帮 | 被官杀克、耗泄重 |
| 调候 | 出生季节寒暖适中 | 过寒/过热需调候 |

身强 → 喜克泄耗（官杀/财/食伤为用）

身弱 → 喜生扶（印/比为用）

中和 → 看大运走势，走到哪边倒向哪边

### 技法三：格局取用法

脚本已经计算出格局，但你要知道格局的解读含义：

#### 正格（八种普通格局）

| 格局 | 解读方向 |
| --- | --- |
| 正官格 | 适合公职/管理，喜印护官 |
| 七杀格 | 适合武职/创业/竞争行业，喜食神制杀或印化杀 |
| 正财格 | 适合稳定求财，喜食伤生财 |
| 偏财格 | 适合经商/投资，胆子大来钱快但波动也大 |
| 正印格 | 适合学术/文职/医疗，喜官杀生印 |
| 偏印格 | 适合特殊技能/玄学/研究，想法独特 |
| 食神格 | 适合艺术/教育/餐饮，性格温和 |
| 伤官格 | 适合创意/技术/自由职业，才华横溢但容易得罪人 |

#### 从格（特殊格局）

- 从旺格 → 顺其旺势，忌逆势操作
- 从弱格 → 顺其弱势，不能帮不能扶
- 化气格 → 以化出之五行为用
### 技法四：十神组合交叉法

十神的关键不是单个出现，而是组合。重点关注：

#### 官杀组合

- 官杀混杂（正官+七杀同时出现）→ 事业选择困难、容易走弯路，女命感情复杂
- 官星配印 → 权力+名望，适合体制内
- 食神制杀 → 以才华制衡压力，适合技术性管理
#### 财星组合

- 财星配官 → 财生官，用财富换取地位
- 财星破印 → 有钱但没文化/名声受损，富而不贵
- 食伤生财 → 靠才华/技术/口才赚钱
#### 印星组合

- 印星护官 → 有靠山/文凭加持
- 印星夺食 → 思虑过多、行动力不足
- 财星坏印 → 为钱放弃原则/学业中断
#### 比劫组合

- 比劫夺财 → 破财、合作纠纷、感情竞争
- 比劫生食伤 → 靠朋友/团队合作生财
#### 十神在四柱的常见断语

| 配置 | 断语 |
| --- | --- |
| 年柱正官 | 祖上为官，出身正统 |
| 年柱七杀 | 祖业飘零，白手起家 |
| 月柱正印 | 父母慈爱，书香门第 |
| 月柱比劫 | 兄弟多、竞争早 |
| 日支坐比劫 | 婚姻竞争、配偶个性强 |
| 日支坐正财 | 配偶贤惠、婚姻稳定 |
| 时柱食神 | 子女聪慧，晚年享福 |
| 时柱伤官 | 子女叛逆但聪明 |

### 技法五：刑冲合害优先级（盲派核心）

盲派认为：穿（相穿）> 冲 > 合 > 破 > 刑。解读时按这个优先级来。

#### 相穿（六穿 / 六害）— 杀伤力最强

- 子未穿、丑午穿、寅巳穿、卯辰穿、申亥穿、酉戌穿
- 穿 = 暗中破坏、慢性伤害、不可修复
- 某柱被穿 → 该柱代表的领域有长期隐患
#### 六冲 — 激烈变动

- 子午冲、卯酉冲、寅申冲、巳亥冲、辰戌冲、丑未冲
- 冲 = 突然变化、分离、冲突
- 年日冲 → 离祖发展
- 月日冲 → 夫妻/家庭矛盾
- 日时冲 → 晚年不安
#### 六合 / 三合 — 缓和/助力

- 合 = 合作、团结、牵绊
- 合化成功则转为化出五行的力量
- 日支被合 → 配偶有外缘或被牵制
#### 六破 — 轻微损耗

- 破 = 损耗、破费但不致命
#### 三刑 — 是非/麻烦

- 寅巳申刑 → 无恩之刑，人情淡薄
- 丑未戌刑 → 持势之刑，恃强凌弱
- 子卯刑 → 无礼之刑，感情困扰
### 技法六：用神落地法

脚本已给用神（喜神/忌神）。关键要看的是：

1. 用神有没有出现在四柱中？哪一柱？
1. 用神有没有根？地支藏干中有没有？
1. 用神受不受克？被哪个十神/地支伤害了？
1. 用神的季节力量：月令是否支持用神五行？
用神在年柱 → 祖上荫庇，贵人较早出现

用神在月柱 → 青年顺利，父母助力大

用神在日支 → 配偶是贵人，中年转运

用神在时柱 → 晚年发达，子女带来好运

忌神在年柱 → 出身寒微，祖业不保

忌神在日支 → 婚姻拖累，中年压力大

忌神在时柱 → 晚年需注意，子女不省心

### 技法七：大运流年互动法

大运是十年大环境，流年是每年具体事件。原局是种子，大运是土壤，流年是天气。

#### 看大运的方法

1. 当前第几步大运？起运年龄多少？
1. 大运干支的五行与日主的关系（是喜是忌？）
1. 大运与原局的刑冲合害：大运地支冲原局某柱 → 该柱领域有重大变化
1. 大运天干与原局天干合化 → 新格局形成
#### 看流年的方法

1. 流年干支是什么？与当前大运的关系？
1. 流年地支与原局四柱的刑冲合害 → 哪个领域被触发
1. 流年天干与日主的十神关系 → 该年的事业/财运/感情主题
1. 特别注意：流年与大运同时冲同一柱 → 剧烈变化
#### 大运流年断语参考

| 配置 | 断语 |
| --- | --- |
| 大运冲用神 | 此运十年多阻逆，求谋不顺 |
| 大运合忌神 | 凶事化小，压力缓解 |
| 流年遇贵人 | 该年有长辈/上级提携 |
| 流年犯太岁（冲年支） | 变动之年，宜静不宜动 |
| 流年与日柱天合地合 | 婚恋/合作机缘 |
| 流年穿日支 | 婚姻/家庭内部出问题 |

### 技法八：神煞触发条件

脚本列出神煞列表，但不是所有神煞都重要。重点关注：

#### 吉神触发条件

- 天乙贵人：合日主或与用神同柱 → 大贵人，关键时候有人帮
- 文昌贵人：在年/月柱 → 学业好；在时柱 → 子女学业
- 桃花（咸池）：在日/时支 → 异性缘佳；被合/冲 → 桃花应事
- 驿马：被冲 → 远行/搬迁/工作变动
#### 凶神触发条件

- 羊刃：与日主同五行且为阳干 → 性格刚烈、易有血光；被合则减凶
- 劫煞：在年/月柱忌神位 → 破财、被劫
- 孤辰寡宿：在日/时柱 → 晚婚或孤独倾向
- 元辰：与日支相冲 → 一生多阻
### 技法九：盲派特色技法（穿破优先）

以下是盲派区别于传统子平的核心技法：

#### 以病取用

- 先找"病"：穿破多？入墓多？过旺？过弱？
- 再找"药"：能制住病的五行就是用神
- 穿破2处以上 → 六亲多损，需重点制化
- 入墓2处以上 → 主事受困，宜静不宜动
#### 墓库论

- 天干入墓 → 该天干代表的人/事受困
- 墓库逢冲 → 墓库打开，被关住的力量释放（吉凶要看冲的是什么）
- 财星入库 → 财不露白，积蓄能力强但花出去也难
#### 时辰断法（脚本会输出）

- 子午卯酉时生 → 兄弟姐妹2-3人，脸型偏圆
- 寅申巳亥时生 → 兄弟姐妹3-4人，脸型偏方
- 辰戌丑未时生 → 兄弟姐妹1-2人，脸型偏长

## 七、解读铁律

### 不得顺着问卦人的信息解

问卦人给出的信息（包括转述的对方情况、猜测、希望）：

- × 不可 作为直接对应来解读
- × 不可 顺着对方的感情倾向或期待给出答案
- √ 可以 作为假设方向 — 把对方说的当成"卦象可能应在这里"的猜想
- √ 可以 大胆假设，小心求证 — 用卦象去验证或推翻这个猜想
- √ 可以 联想，但联想必须有卦象依据
### 交叉验证原则

- 同一个假设，可以用多种技法从不同角度验证
- 技法之间结论矛盾时，如实呈现，不强行调和
- 没有依据的解读不如不解读
核心：卦象说什么就是什么。不是在满足问卦人的期待，而是在读象。

### 紧扣主题

八字信息量极大，同一个盘可以读事业/财运/感情/健康等多个方向。所有解读必须紧扣问卦人的核心问题。

- 对方问事业 → 只看事业相关象意，不跑到感情/健康上去
- 对方问感情 → 不扯财运
- 如果其他宫有明显冲突信号，可以提一句"顺便说一下XX也有这个象"，但不能展开成主线
### 联想纪律

联想 = 从五行/十神/神煞本象出发延伸，不是字面关键词造句。

解读分两层呈现：

- 卦象直给：八字原始数据（干支、十神、格局、生克关系）
- 推测：基于八字做的延伸联想（标清楚"以下是我猜的"）
结论句要具体直白。能说"财运差"就不说"财务方面可能需要多加注意"。卦象只能到抽象层时就说"卦象只能到这，以下是我推测"，然后具体地猜。

先问自己：这个联想是从五行/十神的本源推出来的，还是从一个衍生词出发造句的？

## 九、解读后自检

输出前核对以下要点：

- 结论紧扣用户问题了吗？还是跑到了相关性弱的方向？
- 有没有把用户的猜测当成事实来读？（见"不得顺着用户信息解"）
- 推测部分有没有标清楚"以下是我猜的"？
- 有多个技法时结论是否一致？不一致时是否如实呈现了？
- 有没有不必要的空洞修辞？（如果有 → 删掉，用直白的话重写）
