# 三术命盘研究台

非商业研究原型：紫微、八字、吠陀分别分析后，仅比较一致与冲突。
传统命理解读并非已证实的预测方法，不替代医疗、法律或财务专业意见。

## 运行

使用 Docker 构建。前端为静态网页，后端为 Python + Node 确定性排盘、
分阶段模型任务和 JSON 研究协议校验。完整 Skill 原文在 skill-packs/v1。

```sh
docker build -t three-chart-research .
docker run --rm -p 10000:10000 --env DATABASE_URL --env DASHSCOPE_API_KEY three-chart-research
```

DATABASE_URL 使用 PostgreSQL SSL 连接；DASHSCOPE_API_KEY 只设为服务端密钥。
可通过 QWEN_MODEL 设置百炼支持的模型，默认值见 render.yaml。
接口健康检查：/api/health。单术和比较请求创建后台任务，再轮询 progress。
已完成阶段会保存；刷新或服务重启后可在历史记录恢复。

## 免费部署限制

render.yaml 指定 Render Free。Neon 数据库需另外创建 Free 项目。
免费托管会休眠，有冷启动和资源上限，不保证持续在线；模型 API 另行计费。
单进程、单分析任务串行执行，队列上限 12，每 IP 每小时最多新建 6 个会话。

## 数据边界

会话标识保存在当前浏览器。服务端保存出生信息、报告、排盘与模型诊断；
冻结/处理中的数据保留窗口为 24 小时，过期后不可查询，清理在服务启动、
创建会话等时机进行。云平台自己的日志、数据库备份可能另有保留期。
出生及排盘数据会发送给通义千问；需要外部匹配时地点会发送给地理服务。
用户可主动删除会话。仅凭不可猜测的会话标识访问，不是实名账户系统。
生产密钥只配置在托管平台，不能写入源码、前端或公开日志。
